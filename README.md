# 🪙 Crypto Dashboard

A sleek and responsive cryptocurrency dashboard built with **React**, **Vite**, and **Tailwind CSS**. It provides real-time data, charts, and statistics for top cryptocurrencies.

🚀 [Live Demo](https://crypto1-lovat.vercel.app/)

---

## ✨ Features

- 📈 Live cryptocurrency prices
- 🔍 Search and filter coins
- 📊 Charts with historical data
- 🌙 Dark/light mode support
- ⚡ Fast and responsive UI using Vite + Tailwind CSS

---

## 🖥️ Tech Stack

- **React**
- **Vite**
- **Tailwind CSS**
- **CoinGecko API** (for market data)
- **Chart.js** or **Recharts** (for graphs)
- **Vercel** (for deployment)
